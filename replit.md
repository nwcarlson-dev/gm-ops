# 2026 NFL Mock Draft Simulator

## Overview
A static HTML-based NFL Mock Draft Simulator that allows users to simulate draft picks for NFL teams.

## Project Structure
- `index.html` - Main mock draft simulator page
- `draft-room.html` - Draft room interface
- `dev-guide.html` - Developer guide documentation
- `brand-guidelines.html` - Brand/style guidelines
- `gm-ops-logos.html` - GM operations logos
- `dev-planning-transcripts.html` - Development planning transcripts
- `transcripts/` - Transcript files
- `data/` - Data files and scripts for pulling NFL data

## Running the Project
The project is served using Python's built-in HTTP server on port 5000.

## Deployment
Configured as a static site deployment serving from the root directory.
