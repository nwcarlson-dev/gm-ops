🎯 Project Overview

GM Ops is a web-based NFL simulation game starting with a Mock Draft Simulator and expanding to a full franchise simulation experience.

2 GM Ops: Offseason Planned
3 GM Ops: Franchise Planned

  • Potential subscription model in the future
  • Google Sheets integration for data storage/export
  • Firebase as potential backend for subscription features

Target Audience

  • Fantasy football enthusiasts in their 30s-40s
  • Serious football nerds who want realistic GM simulation
  • Users who appreciate deep roster-building mechanics over arcade gameplay

🏈 Branding & Identity

Brand Name

GM Ops (General Manager Operations)

Why "GM Ops"?

  • Instantly football? ✅ "GM" in sports context = General Manager building a roster
  • Modern feel? ✅ "Ops" has that clean, tech/startup energy
  • Implies the right scope? ✅ GM operations = drafting, signing, trading, cutting
  • Doesn't imply stadium management? ✅ "GM Ops" feels player/roster focused
  • Scales well? ✅ GM Ops: Draft, GM Ops: Offseason, GM Ops: Franchise
  • Easy to say? ✅ Two syllables, punchy
  • Memorable? ✅ Short, clean

Name Evolution

Originally considered "The League" (inspired by the FX TV show), but discovered trademark conflicts:

  • The League App, Inc. (Match Group) owns "THE LEAGUE" trademark in Class 9 (software/apps)
  • Match Group is a $3B company with significant legal resources
  • Both products would be in the same trademark class

Decision: Pivoted to "GM Ops" which is unique, ownable, and equally effective.

Sub-brand Text Specifications

  • Font: Barlow Condensed Bold
  • Letter spacing: 4px
  • Alignment: Right-aligned (right edge aligns with right edge of OPS block)
  • Skew: Same -12deg as main logo
  • Color (dark bg): Silver (#A5ACAF)
  • Color (light bg): Dark Navy (#0A1628)

Favicon Specifications

For favicons and small sizes, the full "GMOPS" text won't be readable. Use simplified versions:

  • favicon-gmops.svg - Simplified GM OPS blocks (for larger icon contexts)
  • favicon-gm.svg - Just "GM" in the red block (for 16x16 and 32x32)

Favicon sizes needed: 16x16, 32x32, 180x180 (Apple touch), 192x192, 512x512

⚖️ Legal Considerations

What's Allowed (Nominative Fair Use)

  • ✅ Real NFL team names (Cowboys, Patriots, etc.)
  • ✅ Real player/prospect names
  • ✅ "NFL Draft" terminology
  • ✅ Team colors
  • ✅ City names + team references
  • ✅ Commentary/analysis tools

What's NOT Allowed

  • ❌ Official NFL shield logo
  • ❌ Team logos (star, horseshoe, etc.)
  • ❌ Anything implying official NFL endorsement
  • ❌ Selling merchandise with NFL marks
  • ❌ "NFL" in product/company name

Required Disclaimer

This application is not affiliated with, endorsed by, or connected to the National Football League (NFL), NFL Players Association (NFLPA), NCAA, or any professional or collegiate football team. All team and player names are used for commentary and analysis purposes.

Safe Harbor Strategy

  • Ship with real team names (nominative fair use for commentary)
  • Use team colors but NO logos
  • Allow user imports for custom data via Google Sheets
  • Clear "Not affiliated with NFL" disclaimer
  • Position as commentary/analysis tool

📋 Current Features - Mock Draft Simulator

Setup Screen (index.html)

Team Selection

  • All 32 NFL teams
  • Sort by draft order or alphabetical
  • Select all / deselect all
  • Team cards showing:
    • Pick number
    • Team name
    • Record
    • Team colors
  • Expandable details panel per team

Settings Panel

  • Number of rounds (1-7)
  • Positional value slider
  • Draft for needs slider
  • CPU-to-CPU trades toggle
  • "Enter Draft" button

Draft Room (draft-room.html)

Draft Board

  • Full 7-round draft order (224 picks)
  • Real 2026 draft order with traded picks
  • CPU draft logic with BPA + team needs
  • Round-by-round navigation

Big Board

  • 100+ players
  • Player cards with scouting data
  • Consensus ranges
  • Strengths/weaknesses
  • Fit analysis grades

User Features

  • Team needs tracking (updates when positions filled)
  • Starred players / watchlist
  • Position filtering
  • Search functionality

Sim Controls

  • Manual (pick by pick)
  • Slow (animated)
  • Fast
  • Instant (sim to user pick)

Audio

  • Draft jingle plays on setup screen

📊 Data Model

Team Data Structure

{
  n: "Raiders",                    // Team name
  p: 1,                            // Pick number
  c: "#000000",                    // Primary color
  rec: "3-14",                     // Record
  oc: "OC Name",                   // Offensive coordinator
  dc: "DC Name",                   // Defensive coordinator
  offScheme: "...",                // Offensive scheme
  defScheme: "...",                // Defensive scheme
  offNeeds: [                      // [isCritical, position, archetype]
    [true, "Quarterback", "Dual-Threat"],
    [false, "Wide Receiver", "Field Stretcher"]
  ],
  defNeeds: [...],
  summary: "..."                   // Key notes
}

Prospect Data Structure

{
  name: "Player Name",
  pos: "QB",
  school: "University",
  rank: 1,
  consensusMin: 1,
  consensusMax: 5,
  strengths: ["Arm strength", "Mobility"],
  weaknesses: ["Processing speed"],
  // Additional scouting data...
}

Why This is Doable

1. Turn-based

No physics engine, no real-time rendering. Just decisions and outcomes.

2. Modular

Each feature builds on the last. Draft → Offseason → Full Season.

3. Data Available

Public NFL data is abundant. Users can import their own via Google Sheets.

4. Web Tech is Perfect

HTML/CSS/JS handles forms, tables, and UI interactions beautifully.
