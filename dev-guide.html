Web-based game (no app store needed) - Potential subscription model in the future - Google Sheets integration for data storage/export - Firebase as potential backend for subscription features --- ## 🏈 Branding ### Brand Name **GM Ops** (General Manager Operations) - "GM" = Acronym (all caps) - "Ops" = Abbreviation (capital O, smaller PS at 80% size to indicate it's not an acronym) ### Logo Specifications | Element | Value | |---------|-------| | Primary Font | **Teko Bold** | | Sub-brand Font | **Barlow Condensed Bold** | | Skew Angle | **-12 degrees** (leaning right) | | PS Size | **80%** of O height | ### Color Palette | Color | Hex | Usage | |-------|-----|-------| | NFL Red | `#D50A0A` | GM block background | | NFL Blue | `#013369` | Ops block background | | White | `#FFFFFF` | Text, light backgrounds | | NFL Silver | `#A5ACAF` | Secondary elements | | Dark Navy | `#0A1628` | Dark backgrounds | ### Logo Variants Needed 1. **Parent:** GM Ops (no sub-brand) 2. **Draft:** GM Ops + "DRAFT" sub-text 3. **Offseason:** GM Ops + "OFFSEASON" sub-text 4. **Franchise:** GM Ops + "FRANCHISE" sub-text Each variant needs dark background and light background versions. ### Sub-brand Text Specifications - Font: Barlow Condensed Bold - Letter spacing: 4px - Right-aligned (right edge of text aligns with right edge of OPS block) - Same -12deg skew as main logo - Color: Silver (`#A5ACAF`) on dark backgrounds, Dark Navy (`#0A1628`) on light backgrounds --- ## ⚖️ Legal Considerations ### What's Allowed (Nominative Fair Use) - ✅ Real NFL team names (Cowboys, Patriots, etc.) - ✅ Real player/prospect names - ✅ "NFL Draft" terminology - ✅ Team colors - ✅ City names + team references - ✅ Commentary/analysis tools ### What's NOT Allowed - ❌ Official NFL shield logo - ❌ Team logos (star, horseshoe, etc.) - ❌ Anything implying official NFL endorsement - ❌ Selling merchandise with NFL marks - ❌ "NFL" in product/company name ### Required Disclaimer ``` This application is not affiliated with, endorsed by, or connected to the National Football League (NFL), NFL Players Association (NFLPA), NCAA, or any professional or collegiate football team. All team and player names are used for commentary and analysis purposes. ``` ### Safe Harbor Strategy - Ship with real team names (nominative fair use for commentary) - Use team colors but NO logos - Allow user imports for custom data via Google Sheets - Clear "Not affiliated with NFL" disclaimer - Position as commentary/analysis tool --- ## 🛠️ Technical Architecture ### Tech Stack - **Frontend:** Vanilla HTML/CSS/JavaScript (single-file architecture for now) - **Hosting:** GitHub Pages (free) - **Data Storage:** Google Sheets (for MVP), Firebase (for subscription features) - **Version Control:** GitHub ### Repository Structure ``` gm-ops/ ├── index.html # Setup screen (main entry) ├── draft-room.html # Draft simulator ├── brand-guidelines # Brand guide HTML ├── README.md └── (future) ├── css/ ├── js/ └── data/ ``` ### GitHub Pages - URL: `https://nwcarlson-dev.github.io/gm-ops/` - Deploy from: main branch, root folder --- ## 📋 Mock Draft Simulator - Current Features ### Setup Screen (`index.html`) - Team selection (32 NFL teams) - Sort by draft order or alphabetical - Select all/deselect all - Team cards with: - Pick number - Team name - Record - Team colors - Expandable details panel - Settings panel: - Number of rounds (1-7) - Positional value slider - Draft for needs slider - CPU-to-CPU trades toggle - "Enter Draft" button ### Draft Room (`draft-room.html`) - Full 7-round draft order (224 picks) - Real 2026 draft order with traded picks - CPU draft logic with BPA + team needs - Big board with 100+ players - Player cards with: - Scouting data - Consensus ranges - Strengths/weaknesses - Fit analysis grades - User team needs tracking (updates when positions filled) - Starred players / watchlist - Position filtering - Search functionality - Sim controls (manual, slow, fast, instant) - Round-by-round navigation --- ## 🚧 Mock Draft Simulator - TODO (10-20 hours) ### High Priority | Feature | Est.
